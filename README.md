# Joshua Caspillo | AI Automation Portfolio

A plain static website. No build step, no dependencies.

## Files

| File | What it is |
| --- | --- |
| `index.html` | All the page content: text, links, sections |
| `styles.css` | Colors, fonts, layout and animations |
| `script.js` | Dark/light toggle, slim nav bar, scroll animations |
| `assets/photo.jpg` | Your portrait |
| `assets/project-1.png` to `project-4.png` | Project screenshots |
| `assets/favicon.svg` | Browser tab icon |

## Put it online with GitHub Pages (free)

1. Create a GitHub account and click **New repository**. Name it, for example, `portfolio`. Keep it **Public**.
2. On the new repository page click **uploading an existing file**. Drag in everything from this folder (`index.html`, `styles.css`, `script.js`, `README.md` and the whole `assets` folder), then click **Commit changes**.
3. Open **Settings > Pages**. Under **Build and deployment** set **Source** to **Deploy from a branch**, choose branch **main** and folder **/ (root)**, then **Save**.
4. Wait about a minute and refresh the Pages screen. Your link appears at the top: `https://YOURUSERNAME.github.io/portfolio/`.

If you name the repository `YOURUSERNAME.github.io`, the site goes live at `https://YOURUSERNAME.github.io/` with no extra path.

## Updating it later

- Open a file on GitHub, click the pencil icon, edit, then **Commit changes**. The live site refreshes in a minute or two.
- To change the photo, open the `assets` folder, click **Add file > Upload files**, and upload a new image named exactly `photo.jpg`. Best size: 1200 x 1500 px (4:5), head and shoulders.
- To change your brand colour, search `styles.css` for `--brand`. Light and dark mode each have their own colour values at the top of the file.

## Your own domain (optional)

Buy a domain, then in **Settings > Pages** enter it under **Custom domain** and follow GitHub's DNS instructions.
